# Extension Icons

This directory should contain the following icon files for the browser extension:

- `icon16.png` (16x16 pixels)
- `icon48.png` (48x48 pixels)
- `icon128.png` (128x128 pixels)

You can create these icons using any image editing software like Photoshop, GIMP, or online tools like Canva.

## Icon Guidelines

1. Use a simple, recognizable design that works well at small sizes
2. Make sure the icon is visible against both light and dark backgrounds
3. Use the same design for all sizes, just scaled appropriately
4. Save as PNG format with transparency

## Placeholder Icons

Until you create custom icons, you can use placeholder icons:

1. Visit a site like [favicon.io](https://favicon.io/) to generate simple icons
2. Download free icons from sites like [Flaticon](https://www.flaticon.com/) or [Icons8](https://icons8.com/)
3. Use a simple colored square with a letter (like "R" for Reader) as a temporary icon

Remember to replace these placeholder instructions with actual icon files before publishing your extension.
